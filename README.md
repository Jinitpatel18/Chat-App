# Real-Time Chat Application

A full-stack real-time chat app built with **React (Vite)** + **Node.js + Express + Socket.io** and **MongoDB**.

## ✨ Features

- 💬 Real-time messaging via Socket.io
- 📜 Persistent chat history (MongoDB)
- ⏱️ Message timestamps
- 👥 Online users count
- ⌨️ Typing indicator
- 🟢 Connect/disconnect notifications
- 🔐 Simple username-based login (dummy auth)
- 🎯 REST APIs for send & fetch messages (fallback)
- 📱 Responsive UI

## 🛠️ Tech Stack

**Frontend:** React 18, Vite, Socket.io-client, Axios
**Backend:** Node.js, Express, Socket.io, Mongoose
**DB:** MongoDB
